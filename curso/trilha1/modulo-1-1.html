1

Separe a receita de quem cozinha

O que é

Uma skill é um procedimento reutilizável que orienta um agente em uma tarefa. Na analogia do vídeo, o resultado é a panqueca, o agente é o cozinheiro e a skill é a receita. O arquivo registra decisões que você não quer explicar novamente a cada pedido.

Por que aprender

Sem um procedimento, o agente precisa preencher lacunas: tamanho, formato, fontes e critérios de qualidade. Registrar essas escolhas reduz variações evitáveis. Isso não torna a geração infalível: ingredientes diferentes e ferramentas indisponíveis ainda mudam o resultado.

Conceitos-chave

Entradao material recebido.
Processoas ações e decisões.
Saídao artefato entregue.
Aceitea evidência de que a entrega serve.
EXEMPLO COMENTADO · 1.1.1 
Pedido solto: “Faça meu relatório.”
Pedido com contrato: “Transforme este CSV em um resumo
semanal, com totais por canal, período e pendências.”

✓ Faça assim

Nomeie a entrada e mostre uma saída aprovada.

✗ Evite este erro

Prometer resultados idênticos só por existir um SKILL.md.

Leve para sua skill. A receita orienta o trabalho, mas não compra ingredientes nem prova o prato sozinha. Use esse princípio para revisar o exemplo antes de avançar.

Pratique antes de revelar

Escolha uma tarefa que você repetiu três vezes e descreva a entrada e a saída em uma frase.

Ver resposta comentada

Exemplo: “A partir de um CSV de vendas da semana, produzir um relatório Markdown com total por canal e questões para revisão.” Uma tarefa com fronteiras permite testar a skill.

2

Diferencie prompt, skill, regra e ferramenta

O que é

Um prompt pede algo nesta interação. Uma skill guarda um procedimento especializado. AGENTS.md registra orientações duráveis do projeto. Uma ferramenta executa uma capacidade concreta, como ler um arquivo ou consultar um serviço. Essas peças se complementam.

Por que aprender

Quando tudo vai para a regra global, detalhes de uma tarefa passam a influenciar tarefas sem relação. Quando tudo fica no prompt, você repete instruções. Separar os papéis ajuda a encontrar o lugar correto para cada correção.

Conceitos-chave

Promptintenção e dados da execução.
Skillmétodo reutilizável.
AGENTS.mdconvenções do projeto.
Ferramentacapacidade e acesso.
EXEMPLO COMENTADO · 1.1.2 
Prompt: “Faça o relatório de setembro.”
AGENTS.md: “Documentação deste projeto é em português.”
Skill: “Valide dados, calcule, redija e confira.”
Ferramenta: leitor de CSV ou script de cálculo.

Do conceito à ação

  1. Pedido: identificar a condição inicial.
  2. Orientações: aplicar a decisão descrita.
  3. Procedimento: conferir o efeito no exemplo.
  4. Ferramentas: registrar a evidência de saída.

✓ Faça assim

Coloque a regra de cálculo junto do processo que a usa.

✗ Evite este erro

Tratar MCP como sinônimo de skill ou como acesso automático.

Pratique antes de revelar

Onde deve ficar a regra “não inventar números ausentes no relatório”?

Ver resposta comentada

No contrato da skill de relatório, com comportamento para dados ausentes. Se for uma exigência geral do projeto, pode também aparecer na orientação do projeto, sem duplicar versões contraditórias.

3

Encontre tarefas que merecem uma skill

O que é

O melhor primeiro candidato é uma tarefa frequente com uma definição de bom que você consegue mostrar. Não precisa ser complexa. Uma descrição de vídeo, uma revisão de texto ou um relatório curto já permite aprender o ciclo inteiro.

Por que aprender

Começar por “gerenciar meu negócio” mistura planejamento, escrita, contas e publicação. Você não consegue localizar o erro. Uma tarefa menor produz um artefato avaliável e dá feedback mais rápido, antes de conectar sistemas importantes.

Conceitos-chave

Frequênciaquantas vezes se repete.
Custo do erroo que uma falha causa.
Observabilidadecomo reconhecer acerto.
Escopoonde a tarefa termina.
EXEMPLO COMENTADO · 1.1.3 
Candidato A: revisar um parágrafo → fácil de comparar.
Candidato B: preparar relatório local → números verificáveis.
Candidato C: operar toda a empresa → escopo amplo demais.

✓ Faça assim

Comece com uma saída local que possa ser revisada.

✗ Evite este erro

Ligar a primeira versão diretamente a envios ou alterações externas.

Pratique antes de revelar

Compare duas tarefas suas usando frequência, clareza de saída e custo do erro.

Ver resposta comentada

Prefira a que combina repetição, saída clara e revisão barata. Uma tarefa menos frequente pode vencer se o retrabalho for alto; justifique o critério, em vez de usar uma pontuação sem contexto.

4

Desenhe o contrato de entrada e saída

O que é

O contrato descreve o que precisa chegar, o que será produzido e o que acontece quando falta informação. No nosso laboratório, o CSV contém data, canal e valor. A saída traz período observado, total, totais por canal e pendências.

Por que aprender

Dados ausentes não devem virar suposições silenciosas. Se “valor” não existe, a skill não consegue calcular faturamento. Uma resposta útil identifica o campo faltante, interrompe apenas a etapa dependente e preserva o material original.

Conceitos-chave

Pré-condiçãodados mínimos.
Pós-condiçãoconteúdo obrigatório.
Invariantealgo que não pode mudar.
Falha previstaresposta útil sem inventar.
EXEMPLO COMENTADO · 1.1.4 
Entrada: UTF-8, colunas data,canal,valor.
Valor: decimal com ponto; moeda BRL definida pelo exercício.
Saída: relatorio.md + qa.json.
Sem coluna obrigatória: informar erro e não gerar relatório.

✓ Faça assim

Defina formato de data e unidade monetária.

✗ Evite este erro

Somar valores de moedas diferentes sem uma regra explícita.

Leve para sua skill. A validação vem antes da redação: escrever bem não conserta uma coluna que não existe. Use esse princípio para revisar o exemplo antes de avançar.

Pratique antes de revelar

Adicione ao contrato uma condição de parada e uma limitação.

Ver resposta comentada

Parar se houver uma data inválida; limitar a análise a totais descritivos, sem inferir causas da mudança de vendas. O contrato deve dizer o que fazer, não apenas listar proibições.

5

Leia criticamente a promessa do vídeo

O que é

Os seis passos são uma proposta prática do autor: partir do resultado, delimitar tarefa, calibrar liberdade, verificar, comparar configurações e incorporar feedback. A expressão “melhor que 99%” é o título promocional da referência, não um resultado medido neste curso.

Por que aprender

O vídeo mostra saídas diferentes entre modelos em uma tarefa visual. Isso é um estudo de caso útil, mas não estabelece um ranking universal. Tempos observados naquela execução também não garantem duração, preço ou qualidade na sua conta.

Conceitos-chave

Relato não equivale a benchmark.
Repetibilidade exige vários casos.
Ferramentas dependem de acesso real.
Autoavaliação exige evidência.
EXEMPLO COMENTADO · 1.1.5 
Hipótese: “Uma configuração mais barata basta para resumos.”
Teste: mesmos casos, mesma rubrica, mais de uma execução.
Conclusão válida: “Nesta amostra, passou nos critérios.”

Do conceito à ação

  1. Relato do autor: identificar a condição inicial.
  2. Hipótese: aplicar a decisão descrita.
  3. Teste local: conferir o efeito no exemplo.
  4. Decisão limitada: registrar a evidência de saída.

✓ Faça assim

Identifique quais conclusões dependem do contexto.

✗ Evite este erro

Repetir percentuais de qualidade sem experimento.

Pratique antes de revelar

Transforme “o modelo caro é sempre melhor” em uma hipótese verificável.

Ver resposta comentada

“Nos nossos casos de seleção de imagens, a configuração A terá menos imagens fora de contexto do que B, usando o mesmo critério de avaliação.” Agora existe uma comparação delimitada.

6

Prepare seu laboratório de aprendizagem

O que é

Você vai trabalhar com dados sintéticos e arquivos locais. Baixe o kit na página inicial, abra a pasta no Codex e mantenha entrada, saída e evidências separadas. O exercício não exige API paga nem uma conta conectada a CRM.

Por que aprender

Separar pastas torna possível refazer uma execução sem substituir o original. A cada mudança, você consegue comparar o relatório anterior com o novo e verificar se a correção trouxe algum efeito indesejado.

Conceitos-chave

dados/entradas imutáveis.
saidas/resultados da execução.
evidencias/testes e observações.
SKILL.mdprocedimento versionável.
EXEMPLO COMENTADO · 1.1.6 
laboratorio/
  dados/vendas.csv
  saidas/
  evidencias/
  .agents/skills/relatorio-semanal/SKILL.md

✓ Faça assim

Guarde uma cópia da entrada usada em cada comparação.

✗ Evite este erro

Trocar dados, modelo e instrução ao mesmo tempo.

Pratique antes de revelar

Abra o CSV do kit e calcule manualmente o total das quatro linhas.

Ver resposta comentada

Os valores 120,50 + 80,00 + 199,50 + 100,00 totalizam R$ 500,00. Essa conta independente será uma referência para verificar o primeiro relatório.
