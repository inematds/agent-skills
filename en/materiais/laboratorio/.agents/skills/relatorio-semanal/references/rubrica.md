# Report rubric
- Blocking: no invented numbers; period and totals correspond to the input.
- Blocking: input preserved; previous outputs aren’t overwritten.
- Clarity: period and total before comments, channels in a table, pending items separated.
- Fidelity: distinguish observation from hypothesis; don’t infer causality.
- Evidence: report opened files, tests executed, and limitations.
- If you can’t verify an item, mark it as “not verified”.
